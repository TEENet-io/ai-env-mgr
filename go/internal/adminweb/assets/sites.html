鏡像裡的 AppLocker 只允許員工運行 Windows 與 Program Files 下的程序；裝在別處的程序（如 C:\tools\Codex） 在強制模式下會提示「系統管理員已阻止這個應用」。這裡的目錄由 agent 在下次同步時寫成 AppLocker 放行規則， 對機器上所有用戶生效。只接受機器級目錄：用戶目錄、AppData、Temp、整盤一律拒絕，否則白名單形同虛設。 目錄必須以 \* 結尾。沒有部署 AppLocker 的機器不受影響。
