## 页面结构

- **Skill 清单**：默认展示业务名称、用途、英文标识、当前版本、派发状态、覆盖人数和版本时间。支持关键词及派发状态筛选，不再在首页展开新增表单和每个 Skill 的员工清单。
- **内容概览**：点击业务名称进入单个 Skill，可查看用途、完整 SKILL.md 原文和随附文件。右侧显示派发概况。
- **派发范围**：员工、部门分别搜索，显示已选数量，可选择当前搜索结果或清空选择。筛选不会取消此前勾选的其他员工。单人试用与正式派发分别呈现；正式派发后须先撤回，才能转为单人试用。
- **历史版本**：按版本倒序展示保存时间、操作者、文件数，明确标记当前使用版本；切换旧版本前确认影响，派发范围保持不变。
- **派发结果**：独立页面，可按员工或电脑搜索，对照应有内容和最新上报；区分已同步、待同步、等待刷新和失败，并保留上报时间。
- **操作记录**：独立页面展示最近 50 条记录，可返回对应 Skill。

## 内容创建和更新

清单页提供“导入 Skill ZIP”和“手动创建”两个入口。编辑页将 ZIP 导入与手动编写分开，只显示当前方式需要填写的内容。

首次导入只需填写业务名称、选择 ZIP；英文标识从 SKILL.md 的 YAML 说明头自动识别。支持根目录 SKILL.md 或同名外层文件夹，仍检查路径、文件类型、链接、大小、名称一致性和内容摘要。存在多个 Skill、名称无效或外层目录与名称不一致时拒绝导入。

新增流程不会覆盖同名 Skill，须进入已有 Skill 的“上传新版”。更新流程固定原英文标识，名称不一致时拒绝保存。保存仍生成新版本并保留派发范围；手动编辑仍可保留、增加或移除附件。

回退和撤回使用现有控制台的确认交互。撤回区域与普通派发操作分开，明确保留内容和历史。保存成功后返回对应 Skill 的内容、派发或版本页面，提示本次实际完成的操作；移除旧的“会关闭 Codex”过时文案。
