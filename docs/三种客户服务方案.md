# AI 工作环境三种服务方案（讨论稿）

版本：2026-10-19
给谁看：和客户沟通的同事。
注意：具体工具、数据范围、服务时段和价格，以双方确认的订单和数据处理约定为准。

三种方案按**我们负责到哪里**来划分。装上某个第三方软件，不等于我们能读取这个软件里的全部对话，文档里也不这样写。

## 先认识几个词

| 词 | 意思 |
|---|---|
| 云电脑 / 远程桌面 | 员工通过网络登录使用的云上 Windows 电脑。 |
| Agent | 装在每台云电脑上的管理程序，负责接收配置、安装软件、上报状态。 |
| Admin | 我们的管理后台。 |
| 模型网关 | 员工调用 AI 模型时经过的中转服务。经过它的调用可以统计用量和费用。 |
| 会话采集 | 收集员工和 AI 工具之间的对话记录。 |
| 适配验收 | 针对某个具体工具或版本，验证采集确实能正常工作。 |
| SLA | 服务水平承诺，例如多久响应、多久修复。 |

## 三种方案对比

### A. 全包 AI 工作间

- **我们提供什么**：
  - 云端远程桌面；
  - 员工开通和停用；
  - 预装经过审核的软件；
  - 设备策略；
  - 由我们管理的模型网关和模型额度；
  - 工单和运行状态查看。
  - 会话采集需要另外确认范围，并通过适配验收。
- **我们维护到哪里**：
  - 维护云电脑、Agent、Admin、网关，以及我们提供的模型渠道；
  - 处理发布、故障和使用问题。
  - 模型供应商自身的故障、第三方软件的功能限制，需要和供应商一起处理。
- **客户负责什么**：确认员工名单、需要的模型和软件、数据采集和留存范围，并按约定验收。

### B. 远程桌面 + 客户自己订阅 AI 工具

- **我们提供什么**：
  - 受管理的远程桌面；
  - 员工和设备管理；
  - 软件安装和基础安全策略；
  - 按审核结果，预装客户自己购买的 AI 客户端。
- **我们维护到哪里**：
  - 维护桌面、Agent、安装包和设备策略；
  - 协助排查软件能不能启动、网络问题和被策略拦截的问题。
  - 第三方 AI 服务的账号、额度、账单、模型质量和供应商故障，不通过我们的网关管理，我们不负责。
- **客户负责什么**：
  - 自己购买、授权和管理 AI 工具账号；
  - 承担订阅费和模型费用；
  - 服务方面的问题，自己找供应商处理。
  - 不得在工单里提交账号密码或密钥。

### C. 本地采集服务（还在等试点）

- **我们提供什么**：
  - 客户继续用自己的电脑和 AI 工具。
  - 试点通过后，在客户批准的设备、人员和工具范围内安装采集组件。
  - 采集组件只通过已验证的文件格式或官方接口，增量收集约定好的数据。
  - 交付约定好的查看、导出和删除流程。
- **我们维护到哪里**：
  - 维护采集组件、上传链路、采集状态，以及我们负责的存储。
  - 不接管客户的电脑、AI 订阅、模型网关或第三方工具本身。
  - 每增加一种工具或一个版本，都要单独验证。
- **客户负责什么**：
  - 提供测试设备和合法的访问权限；
  - 确认采集目的、采集内容、涉及人员、留存周期，以及第三方产品的使用条款；
  - 负责本地设备和软件的日常维护。

## 定制工具和三种方案的关系

定制工具是独立的业务应用或自动化能力。它不是任何一种方案自动附带的功能。

- **方案 A**：定制工具可以接入我们管理的网关。
- **方案 B**：定制工具可以部署在客户桌面上。如果它要调用客户订阅的 AI 服务，要先确认该产品是否提供合法可用的接口和授权。
- **方案 C**：只采集约定的数据，不能代替定制工具的开发、托管和维护。

定制工具的需求、部署位置、数据接口、许可和运维费用，单独列项。

## 数据边界

- **方案 A**：网关能统计经过它的模型调用。
- **方案 B**：客户直接连第三方的调用不经过我们的网关，所以不能承诺像 A 那样的用量和费用对账。
- **方案 C**：只能采集客户授权、并且技术上能验证的数据。不承诺抓取第三方产品的全部历史、云端会话、附件或费用。

任何原始会话采集默认都是关闭的。开启前要写清楚：适用哪些人员、采集哪些字段、存在哪里、保留多久和何时删除、谁有权访问。

现有实现在"采集哪些人"的范围上还有问题。没通过试点验收前，不能承诺方案 C 已经可以交付。

## 给客户的选型建议

- 希望从桌面到模型统一管理：选 **A**。
- 已经有 AI 工具订阅，只需要一个受管理的工作环境：选 **B**。
- 不换现有电脑，只需要经过批准的数据留存：先评估 **C**。

三种方案都可以单独追加定制工具。
