# 月度成本与内部报价粗估

## 估算前提

- 按 **1 家客户、1 名员工、1 台 8 核 16GiB 办公型云电脑、每天用 12 小时**估算。
- 每月按 22 个工作日算，即 **264 小时／月**。
- **全文统一用人民币，月度合计的单位是元／月。**
- 供应商用美元报价的项目，暂按预算汇率 **1 美元＝7.20 元**换算。这不是实时汇率，也不是核实过的账单。

## 先认识几个词

| 词 | 意思 |
|---|---|
| 无影 | 阿里云的云电脑产品。员工用的 Windows 电脑就跑在上面。 |
| Admin 控制台 | 管理员使用的管理后台网页。 |
| PostgreSQL | 管理后台用的数据库。 |
| OSS | 阿里云的对象存储，放安装包、日志和备份。 |
| LiteLLM 网关 | 员工调用 AI 模型时经过的中转服务。 |
| Windows Agent | 装在每台云电脑上的管理程序。 |
| AppLocker | Windows 自带的程序白名单。 |
| 报价底线 | 对外报价不能低于的价格。 |

## 包含哪些模块

| 归属 | 当前纳入核算的模块 |
|---|---|
| 客户工具 | Admin 控制台；客户工单；员工开户/停用；设备管理；模型渠道与批量下发；软件安装/版本发布；网站封禁与 AppLocker；用量/账单展示；任务、告警、审计和管理员权限 |
| AI 工作间 | 无影云电脑；Windows Agent（策略、凭据、状态、日志及可选数据采集）；Codex 和预装软件；LiteLLM 网关及 AWS/GCP/Azure 模型调用 |
| 共用支撑 | Admin/PostgreSQL、OSS/备份、网关主机/网络、监控与值班；只计一次，再分摊到上面两项 |

这里只算**当前主要的服务链路**，不是公司全部产品：

- 没算进去的：RAGFlow、Dify、CI/CD（自动构建发布流程）、研发、销售、第三方软件许可。如果这些要交付给客户，应另外加钱。
- 独立的三云对账采集程序还没有作为长期运行的生产服务，暂不计费。

## 每月成本估算

| 成本模块 | 客户工具／月 | AI 工作间／月 | 这笔钱怎么算 |
|---|---:|---:|---|
| 模型调用 | ? | ? | 客户实际用量未知，不能假设每人固定花费 |
| 服务器／云电脑 | 500–900 | 约 428 | Admin/PostgreSQL 主机预算；1 台云电脑按 **264 小时 × 北京地域参考价约 ¥1.62／小时**估算，磁盘和共用 LiteLLM 主机另算 |
| 网络流量 | 20–50 | 30–100 | 小流量预算；不含 LiteLLM 主机。OSS 同地域内网流出免费，公网流量按实际账单修正 |
| OSS 存储／备份 | 10–20 | 20–60 | 合计暂按 **100–300GB**；不重复算云电脑磁盘或已含在主机费里的数据库磁盘 |
| 运维 | 1,000–2,000 | 1,500–3,000 | 暂按 **¥150/小时**：客户工具约 7–13 小时，工作间约 10–20 小时，区间取整 |
| **已估部分小计** | **1,530–2,970** | **1,978–3,588** | **含 1 台云电脑参考计算费；不含云电脑磁盘、模型调用和共用 LiteLLM 主机** |

**1 人使用时，已估部分合计：¥3,508–6,558／月。**

几点说明：

- Admin 主机、OSS 和基础运维是每家客户环境都要有的固定费用。这里**没有拿 10 人的费用简单除以 10**。
- 完整的月成本还要加上：云电脑磁盘、实际模型费用、共用 LiteLLM 主机的分摊费。云电脑计算费也要按实际地域的价格修正。
- 这些未知项核实之前，**不给出完整的报价底线**。
- 暂定公式仍是 `完整月成本 × 1.10 ÷ 0.80`。其中 1.10 是留 10% 应对风险，÷ 0.80 是保证最低 20% 毛利。不含税，也不含一次性的实施费和许可费。

## 云电脑费用怎么算

无影**按需购买**时：

- 计算费只按开机的小时数收。
- 系统盘和数据盘按持有时间收，关机也要收磁盘费。

[无影官方价格表](https://www.alibabacloud.com/de/product/cloud-desktop/pricing/zh)显示，北京地域的**企业办公型 8 核 16GiB** 目录价是 **0.224996 美元／小时**，按上面的预算汇率约 **¥1.62／小时**。

只拿北京价举例：

- `1 台 × 12 小时 × 22 天 × 0.224996 美元 × 7.20 ≈ ¥428／月`
- 如果每月 30 天都开 12 小时，约 **¥583／月**。

这两个数**都不含磁盘和可能产生的额外带宽费**。

注意：

- 实际用哪个地域、有没有折扣，还没有核实。不能把北京价直接当成我们的账单，报价前必须到控制台确认。
- 之前那种高配 GPU 工作站的小时价，不适用于这批办公型云电脑。

参考：[关机计费规则](https://www.alibabacloud.com/help/en/wuying-workspace/product-overview/billing-faq)、[GPU 工作站价格](https://www.alibabacloud.com/help/en/wuying-workspace/product-overview/graphics-workstation)。

## 共享成本怎么分

共享成本只记一次，再按下面的方式分摊：

- 模型费：按实际是谁调用的来归属。
- 服务器和存储：按用了多少资源分摊。
- 运维：按花了多少工时分摊。

OSS 存储的例子：阿里云新加坡 OSS 标准存储，按预算汇率约 **¥0.1224/GB·月**，所以 100–300GB 的**容量费约 ¥12–37／月**。表中 OSS 合计 ¥30–80，多留了一点给请求费和备份，仍然是预算，不是账单。

参考：[OSS 定价](https://www.alibabacloud.com/en/product/oss/pricing)、[OSS 流量计费](https://www.alibabacloud.com/help/zh/oss/traffic-fees)。

## 还要核实什么

**其余单价仍是预算里先填上的估计值，不是供应商报价。**

拿到以下账单或信息后，用[复算脚本](../costing/monthly_cost.py)把假设值换成真实数字：

- 云电脑规格和开机时长
- 网络费用
- 模型费用
- LiteLLM 主机费用

另外，Google 现在公布的价目表价格不能当作最终结算价。
