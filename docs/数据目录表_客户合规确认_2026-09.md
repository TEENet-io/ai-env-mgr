# AI 工作间数据目录表（客户合规确认稿）

版本：2026-09-26。范围：Windows Agent、Admin 控制台、PostgreSQL、阿里云 OSS/SLS，以及与 LiteLLM 网关交换的数据。本表描述**当前代码和部署配置所能确认的行为**；「建议 Policy」是待客户确认的目标，不代表已实现，也不构成法律结论。实际云资源的生命周期、地域、备份和供应商侧留存须在交付前逐项核验。

## 口径与重要边界

- **关闭采集仅停止后续上传**；不会删除 Windows 源文件、OSS 已上传对象、Agent 本地去重状态或备份。`collectSince` 是按文件最后修改日期（UTC）筛选，留空会补传全部可见历史，不是留存期限。
- 当前会话采集默认关闭。启用后采集原文，不做脱敏；内容可能包含提示词、回复、文件内容/路径及用户主动粘贴的个人信息或密钥。不得将其当作普通运行日志。
- Agent 当前扫描每个普通本地账户（跳过内置 Administrator）；API 上传授权却只接受机器当前绑定员工。共享机器的实际结果是“其他账户可能被本地读取但上传被拒”。**在确定客户允许的采集主体并修复这个差异前，不应启用采集。**
- 旧文档中“离职满 7 天”是**清理提醒**，不是删除动作；自注册且从未绑定的设备 7 天后自动注销则是另一条独立规则。
- 数据删除必须同时考虑在线库、OSS/SLS、副本/备份、Windows 原始文件和网关/模型供应商。只删除 Admin 中的账号或机器不等于全链路删除。

## 建议的删除执行顺序

1. **停止新增**：关闭采集或撤销该员工/设备的上传资格，确认在线及离线机器不会恢复后补传；对 D01/D02 尤其重要。
2. **即时撤权**：撤销 LiteLLM 令牌和设备令牌，作废未完成的任务；确认 Admin 与网关状态一致。
3. **删除在线副本**：按员工/设备标识清理 OSS `data_collect`、兼容凭据对象、数据库中的可删记录、Agent 本地凭据/采集状态及云电脑磁盘；记录对象数、失败项和操作者。
4. **处理衍生数据**：核对 SLS、日级费用、审计、发布任务历史和 LiteLLM/云供应商侧数据，依据已确认的例外期限清理或去标识。
5. **处理备份**：备份不可单人原地修改，记录最长剩余 30 天窗口；若恢复了较早备份，必须重放删除清单，防止数据复活。
6. **复核并留证**：OSS 前缀为空、在线库无不应保留的记录、令牌失效、机器/本地副本已处理；删除动作本身写入审计，不把被删正文写进证明材料。

目前系统**尚未实现**上述跨存储的一键删除编排、OSS 会话生命周期与删除回执。因此在这些能力上线和验收前，客户不能据此表获得“到期自动删除全部数据”的承诺。

## 需要客户逐项签认

| 议题 | 待确定选项 / 交付前证据 |
|---|---|
| 是否开启原始会话采集 | 默认关闭；若开启，确认目的、适用员工、共享机器处理方式、是否采集 D02、是否允许历史补传 |
| 会话留存期限 | D01/D02 选 30 / 90 / 180 天或客户指定值；明确起算时间、暂停采集与法律保留例外 |
| 费用/审计期限 | D08/D10 分别确认保存年限、去标识范围、谁可查询与导出 |
| 数据地域和承载账号 | 核对 OSS Bucket、SLS Project、PostgreSQL/备份、LiteLLM 与 AWS/GCP/Azure 的实际地域及账号归属 |
| 删除 SLA 与备份窗口 | 明确在线副本删除时限、备份自然到期的 30 天窗口、恢复备份后的重删流程 |
| 供应商处理条款 | 逐供应商确认请求内容留存、训练使用、子处理方、审计与删除证明，不以平台配置推断 |
| 权限与导出 | 确认哪些管理员可读会话原文、导出需不需要审批/水印、访问日志保存多久 |
